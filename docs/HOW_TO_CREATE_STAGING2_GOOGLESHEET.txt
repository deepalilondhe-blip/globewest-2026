====================================================
 HOW TO CREATE THE GLOBEWEST STAGING 2 GOOGLE SHEET
 Step-by-step instructions to run the Apps Script
====================================================

SCRIPT FILE: docs/GlobeWest_Staging2_GoogleSheet_Script.gs

----------------------------------------------------
 STEP 1: OPEN GOOGLE APPS SCRIPT
----------------------------------------------------
  1. Open your browser
  2. Go to: https://script.google.com
  3. Sign in with your Google account (same account
     where you want the sheet saved)

----------------------------------------------------
 STEP 2: CREATE NEW PROJECT
----------------------------------------------------
  1. Click "New project" (top-left button)
  2. A new script editor opens
  3. DELETE all the existing code in the editor
     (select all with Ctrl+A then Delete)

----------------------------------------------------
 STEP 3: PASTE THE SCRIPT
----------------------------------------------------
  1. Open this file in Notepad or VS Code:
     C:\GlobeWest 2026\docs\GlobeWest_Staging2_GoogleSheet_Script.gs
  2. Select ALL the code (Ctrl+A)
  3. Copy it (Ctrl+C)
  4. Go back to the Apps Script editor
  5. PASTE the code (Ctrl+V)

----------------------------------------------------
 STEP 4: RUN THE SCRIPT
----------------------------------------------------
  1. At the top dropdown, make sure it shows:
     "createStaging2RemediationSheet"
  2. Click the ▶ RUN button (or press Ctrl+R)
  3. A popup will ask for permissions — click
     "Review permissions"
  4. Choose your Google account
  5. Click "Advanced" → "Go to project (unsafe)"
     (this is safe — it's your own script)
  6. Click "Allow"

----------------------------------------------------
 STEP 5: GET YOUR SHEET URL
----------------------------------------------------
  1. After the script runs (takes ~10 seconds)
  2. A popup will appear showing the Google Sheet URL
  3. Copy that URL — share it with your team!
  4. OR: Check your Google Drive for a file called:
     "GlobeWest Staging 2 — Critical Path Remediation"
