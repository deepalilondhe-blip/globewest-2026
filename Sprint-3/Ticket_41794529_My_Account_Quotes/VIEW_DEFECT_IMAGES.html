Pass 01: Default Active Filter Tab (Frame 622 Rule 1: Default to "all")
High Severity Defect
Defect Analysis: Live Staging currently defaults to the OPEN tab upon page load. Frame 622 explicitly states: "Tabs that filter table view of quotes shown based on quote status. Default to 'all'". Figma Rule (Frame 622): "Tabs that filter table view of quotes shown based on quote status. Default to 'all'"
Pass 02: Table Columns & Consolidated Actions Dropdown (Frame 622 Rule 3)
High Severity Defect
Defect Analysis: Live desktop table renders 9 columns with an unstyled redundant DETAILS column in addition to ACTIONS. Figma consolidates all row interactions strictly under a single Actions ∨ dropdown. Also, header copy should read EXP. DATE (abbreviated) instead of full EXPIRY DATE.
Figma Rule (Frame 622): "Actions housed under dropdown for both mobile + desktop as per other table functionality"
Pass 03: Search Bar Row Alignment vs Filter Tabs
Medium Severity Defect
Defect Analysis: In the approved Figma desktop artboard, the Search input (Search [🔍]) is right-aligned on the same horizontal row directly alongside the filter tabs. On live staging, the search bar is pushed onto a disconnected upper position above the table right.
Pass 04: Missing FAQ Accordion Block (Frame 622 Block 2)
Critical Defect (Missing Module)
Defect Analysis: Frame 622 mandates a dedicated FAQ Accordion section directly below the Quotes table. This component is 100% MISSING from the live staging page; after the table there is blank empty space followed directly by the footer.
Figma Rule (Frame 622): "New block utilised throughout the My Account Experience. Each FAQ block will have specific questions related to the page it is on. Admin ability to change content. Ability to add up to 8 FAQs. All accordions closed by default. Only one open at a time."
Pass 05: Missing 'Need help? Contact our sales team' Block (Frame 622 Block 3)
Critical Defect (Missing Module)
Defect Analysis: Below the FAQ section, Figma specifies a dedicated Support/Contact Sales content block with customer support phone, email, and order submission guidelines. This block is completely missing from live staging.
Figma Rule (Frame 622): "NEED HELP BLOCK: Content Block / Admin ability to change content."

Medium Severity Defect
Defect Analysis: Figma artboard specifies numerical pill counter badges next to My Account menu items (e.g., Quotes [723], Holds [3], Orders [3]). Live staging navigation currently lacks count badge integration.
