## Saved Defect Comparison Images

| File Name | Defect Description | Single-Line Summary |
| :--- | :--- | :--- |
| **`Defect_1_Show_Filters_Toggler_Missing.png`** | The horizontal filter toolbar on US Storefront starts directly with filter pills and is missing the dedicated `"Show Filters"` button pinned to the left. | *Defect: The 'Show Filters' toggler button is missing from the horizontal filter toolbar on US Storefront (present in Figma before filter pills).* |
| **`Defect_2_Product_Card_Wishlist_Heart_Missing.png`** | In the Figma design, each product card has a Wishlist Heart icon (`♡`) in the top-right corner opposite to `Compare`. It is completely missing on US Storefront cards. | *Defect: Product cards are missing the Wishlist heart icon in the top-right corner opposite to Compare as specified in Figma.* |
| **`Defect_3_Top_Utility_Bar_Copy_Mismatch.png`** | The top utility bar copy differs between Figma and US Storefront for logged-out visitors. | *Defect: Top utility bar uses 'Ready to Buy / Book Showroom Visit' instead of Figma's 'Become a Trade Customer / Book Showroom Appointment'.* |
| **`Defect_4_Desktop_Filters_Alignment.png`** | Figma sticky note requires: *"Left aligned filters on the page, rather than centred"*. On desktop US Storefront, filters are offset/indented. | *Defect: Desktop filters toolbar is not left-aligned to margin as specified in the Figma design card.* |
